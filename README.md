# All Desk downloads

Releases of All Desk, a remote desktop app for Windows 10 and 11 (64-bit).
This repository holds only the release files; there is no source code here.

Latest version:

- [AllDesk.exe](https://github.com/ErshadRahi/alldesk-downloads/releases/latest/download/AllDesk.exe): the app, for every PC that connects or is connected to.
- [AllDesk.Relay.exe](https://github.com/ErshadRahi/alldesk-downloads/releases/latest/download/AllDesk.Relay.exe): the relay server, for the administrator.
